Interactive Bubble Game

OpenCV + MediaPipe + Pygame

A hand-controlled game inspired by Wii Fit's Balance Bubble game

Features

Nature background
Hand-controlled input
Path decisions

Our game includes a background of a stream. The player tries to navigate to the finish line while avoiding obstacles (rocks) and walls (land). Our game is unique as it utilizes OpenCV and MediaPipe to get user input.
